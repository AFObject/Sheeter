# Sheeter - 高效简洁的高考答题卡生成器

README.md 待完善

目前功能覆盖上海高考等级考（小六门）与语文的常规题型排版

[2026-05-06] 等级考已完结撒花，不再针对等级考优化更新

样式仿上海高考

语法：

```
#split 3          // 栏数（1-6），默认 3
#size 15          // 基础字号（相对值）

# 主标题          // 居中大标题
## 副标题         // 居中副标题

### 大题标题      // 如：### 一、选择题

1. X-4            // 四选一 [A][B][C][D]
2. X-5            // 五选一 [A][B][C][D][E]
2 (1). P          // 判断题 [T][F]，无需参数
3. T-2            // 2个填空（固定宽度）
4. L-3            // 3行书写横线（题号同行起始）
5. B-3            // 编号选填 [1][2][3]
6. J-5            // 解答空白区（5行高度）
K-3               // 无题号空白区（3行高度）
---               // 分割线
===               // 分栏符（跳到下一栏）
任意文字          // 直接显示

// 行首 // 为注释，不渲染
```
