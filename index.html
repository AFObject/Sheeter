📖 语法参考

#split 3          // 栏数（2/3/4），默认3
#size 15          // 基础字号（相对值）

# 主标题          // 居中大标题
## 副标题         // 居中副标题

### 大题标题      // 如：### 一、选择题

1. X-4            // 四选一 [A][B][C][D]
2. X-5            // 五选一 [A][B][C][D][E]
2 (1). P          // 判断题 [T][F]，无需参数
3. T-2            // 2个填空（固定宽度）
4. L-3            // 3行书写横线（题号同行起始）
5. B-3            // 编号选填 [1][2][3]
6. J-5            // 解答空白区（5行高度）
K-3               // 无题号空白区（3行高度）
---               // 分割线
===               // 分栏符（跳到下一栏）
任意文字          // 直接显示

// 行首 // 为注释，不渲染
